# Context

The repository-native `CURRENT.md` model already makes normal conversation replacement cheap, but the User should not need to remember or restate the underlying migration/handoff/current-state rules.

# Accepted direction

User phrases such as:

```text
换对话框，给我提示词
换个对话框
给我新对话框提示词
```

are treated as a request for the normal conversation-resume bootstrap of the active project.

ChatGPT resolves the current repository identity from active context and returns only the compact resume prompt. It does not explain project migration, handoff, CURRENT architecture, or historical context unless the User explicitly asks.

# Canonical prompt

```text
继续 cigit-zgy/<repository>。

这是 conversation resume，不执行 project migration。
按 AGENTS.md → CURRENT.md → design/README.md 恢复当前工作。

只按 CURRENT.md 的 current work edge 按需读取相关 design / Skill / task / report；
不要预读历史。
```

Replace `<repository>` with the actual active repository. If repository identity is genuinely ambiguous, ask only for that identity rather than producing a long explanation.

# Consequence

UPDATE current-work-state runtime behavior.

The exact shorthand behavior belongs in `references/project/current.md` and is routed from `SKILL.md`.
